Name

Myoglobin

Range

Serum roughly female 1-66 ng/mL, male 17-106 ng/mL; urine should be negative/absent

Why

Skeletal muscle injury/rhabdomyolysis cue; myoglobin can injure kidneys, so connect it with CK, potassium, creatinine, urine color, and urine output.
