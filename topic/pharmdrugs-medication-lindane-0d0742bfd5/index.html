Used To Treat

Mechanism

Lindane disrupts parasite neuronal function but can also cause human neurotoxicity. Seizures, overuse, infants/children, pregnancy, skin breakdown, and repeated applications are high-risk.

Boxed Warning

No drug-specific boxed warning is listed for lindane in this nursing reference. Major safety review centers on hypersensitivity, organ toxicity, route-specific hazards, high-alert dosing, population risk, and serious class warnings when present.

Description

Lindane is an organochlorine scabicide/pediculicide and neurotoxic second-line agent: it disrupts parasite neuronal function but can also cause human neurotoxicity. It is used for scabies or lice only when safer first-line therapies have failed or cannot be used.
