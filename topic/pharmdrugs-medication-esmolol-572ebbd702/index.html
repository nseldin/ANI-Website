Used To Treat

Hypertension, angina, rate/rhythm control, post-MI protection, migraine/tremor uses for selected agents, and heart failure with selected evidence-based beta blockers.

Mechanism

Blocks beta-adrenergic receptors, which slows heart rate, decreases contractility, lowers blood pressure, and reduces myocardial oxygen demand.

Contraindications

  • Clarify severe bradycardia, symptomatic hypotension, high-grade heart block without pacing, acute decompensated heart failure, and bronchospasm risk for nonselective agents.

Description

Esmolol is a beta-1 selective ultra-short-acting beta blocker: it blocks beta-adrenergic receptors, which slows heart rate, decreases contractility, lowers blood pressure, and reduces myocardial oxygen demand. It is used for hypertension, angina, rate control, post-MI protection, dysrhythmia control, migraine/tremor uses for selected agents, heart failure with selected evidence-based beta blockers, and pregnancy hypertension with labetalol when ordered.
