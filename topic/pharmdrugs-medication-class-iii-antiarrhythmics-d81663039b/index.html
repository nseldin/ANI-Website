Description

Class III antiarrhythmics are medications grouped by a shared clinical action: block potassium channels and prolong repolarization, which increases the action potential duration and QT interval. Common uses include selected atrial and ventricular rhythm-control situations. Use the linked examples to compare drug-specific warnings, contraindications, labs, and nursing care.
