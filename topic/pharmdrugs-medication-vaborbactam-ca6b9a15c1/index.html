Class

Cyclic boronate inhibitor of KPC and selected class A/C serine beta-lactamases

Used To Treat

Used with meropenem for susceptible complicated urinary tract infection and clinically for selected KPC-producing Enterobacterales according to susceptibility and current guidance.

Boxed Warning

No current U.S. FDA boxed warning. High-yield warning context: Vaborbactam does not rescue meropenem from MBL or OXA-48-like hydrolysis. The resistance mechanism and MIC must fit the combination.

Mechanism

The boronate forms a reversible covalent complex that resembles the tetrahedral transition state generated when a serine beta-lactamase hydrolyzes a beta-lactam. Occupying that catalytic state blocks KPC from destroying meropenem. Meropenem then traverses the outer membrane and acylates PBPs. Porin loss, efflux, very high enzyme expression, altered targets, an MBL, or an OXA-48-like enzyme can still prevent activity. Both components are renally cleared, and the labeled three-hour infusion supports time-dependent meropenem exposure while maintaining inhibitor protection.

Nursing Essentials

  • Confirm KPC or other supported susceptibility, renal function, valproate use, dose, and three-hour infusion before administration because enzyme match and exposure are inseparable.

  • Trend mental status and renal function because meropenem accumulation can cause neurotoxicity even when vaborbactam is correctly matched.

Contraindications

  • Do not use vaborbactam alone because it has no independent antibacterial effect.

  • Avoid carbapenem-valproate coadministration when an active alternative exists because the inhibitor does not prevent the pharmacokinetic interaction.

Interactions

  • Meropenem can profoundly lower valproate; probenecid and OAT3 competition can alter renal elimination.

  • Nephrotoxins can reduce clearance and increase exposure of both components.

Key Labs

  • Culture/MIC, KPC or carbapenemase testing, creatinine/eGFR, CBC, liver tests, mental status, and valproate concentration if exposure occurs.

  • A carbapenem-resistant phenotype without KPC does not establish vaborbactam benefit.

Nclex Traps

  • Vaborbactam is especially a KPC shield; it does not cover metallo-beta-lactamases.

  • Meropenem remains the bactericidal PBP-binding component.

Description

Vaborbactam is a non-beta-lactam cyclic boronate beta-lactamase inhibitor designed to neutralize KPC carbapenemases and selected class A and C serine enzymes. It has no meaningful antibacterial activity alone. By protecting meropenem from KPC-mediated hydrolysis, it can restore the carbapenem's ability to bind PBPs in susceptible Enterobacterales. It does not reliably inhibit class B metallo-beta-lactamases or class D OXA-48-like carbapenemases, so Vabomere is not a universal answer to carbapenem resistance. That enzyme match is why KPC confirmation and the actual combination MIC matter.

Adverse Effects

  • The combination can cause headache, phlebitis, diarrhea, nausea, liver-test elevation, hypersensitivity, CDI, cytopenias, and carbapenem-related neurotoxicity.

  • Meropenem lowers valproate concentrations, so the vaborbactam component does not remove the breakthrough-seizure interaction.
