Summary

Methacholine challenge test is a high-yield Respiratory diagnostic reference. Bronchoprovocation test used when asthma is suspected but baseline spirometry is nondiagnostic.

Quick Answer

Methacholine challenge test: Bronchoprovocation test used when asthma is suspected but baseline spirometry is nondiagnostic. Nursing focus: prepare correctly, protect safety, trend results with assessment, and escalate red-flag findings.

Sections

    • What it tells you

    • Bronchoprovocation test used when asthma is suspected but baseline spirometry is nondiagnostic.

    • Before / preparation

    • Follow instructions about holding bronchodilators or other respiratory medications. Baseline spirometry and rescue bronchodilator availability matter.

    • Priority nursing actions

    • Monitor airway, breathing, oxygenation, cough, bleeding risk, and tolerance before and after respiratory testing.

    • Concerning results / reportable cues

    • Hypoxemia, respiratory distress, hemoptysis, absent breath sounds, pneumothorax signs, or severe bronchospasm.

    • Common NCLEX trap / nuance

    • This test can provoke bronchospasm. Worsening wheeze or respiratory distress requires prompt response.
